# 韩语学堂 · 한국어 배우기

面向中文母语者的韩语入门学习网站。纯静态页面（HTML + CSS + 原生 JavaScript），无需构建、无需后端。

## 功能

| 模块 | 内容 |
| --- | --- |
| **字母** | 14 个基本辅音、5 个双辅音、10 个基本元音、11 个复合元音，附罗马音、中文发音提示、组合示例，以及收音 7 个代表音规则 |
| **拼读** | 选择初声 + 中声 + 终声，实时拼出音节并朗读；“拆字器”可把任意韩文拆成字母 |
| **词汇** | 9 个分类、100+ 高频词；翻卡记忆（键盘 ← → 空格）、列表浏览、标记掌握、只看未掌握、打乱顺序 |
| **短语** | 初次见面、购物点餐、出行问路、沟通求助、日常生活 5 个场景 |
| **语法** | 语序、은/는、이/가、을/를、이에요/예요、-아요/어요 |
| **测验** | 字母→罗马音、韩→中、中→韩、听音选词四种题型，每轮 10 题，记录最佳成绩与正确率（键盘 1–4 作答） |

- 发音使用浏览器自带的 Web Speech API（`ko-KR`）。若系统未安装韩语语音，可在系统设置中添加。
- 学习进度（已掌握词汇、答题统计、连续学习天数）保存在浏览器 `localStorage` 中。
- 支持手机端与深色模式。

## 本地运行

直接双击打开 `index.html` 即可；或启动一个本地服务器：

```bash
python3 -m http.server 8000
```

然后访问 <http://localhost:8000>。

## 部署

仓库根目录就是网站根目录，可直接用 GitHub Pages（Settings → Pages → 选择分支和 `/ (root)`）、Netlify、Vercel 等托管。

## 目录结构

```
index.html      页面骨架与导航
css/style.css   样式（含响应式与深色模式）
js/data.js      学习内容：字母、词汇、短语、语法
js/app.js       路由、朗读、拼读、翻卡、测验、进度存储
```

想添加词汇或短语，只需编辑 `js/data.js` 中对应的数组。
