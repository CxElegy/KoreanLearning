# 韩语学堂 · 한국어 배우기

面向中文母语者的韩语入门学习网站。纯静态页面（HTML + CSS + 原生 JavaScript），无需构建、无需后端。

## 功能

| 模块 | 内容 |
| --- | --- |
| **字母** | 14 个基本辅音、5 个双辅音、10 个基本元音、11 个复合元音，附罗马音、口型舌位的发音方法、男女声示范、组合示例，以及收音 7 个代表音规则 |
| **发音** | 松音·送气音·紧音对比（含“纸片测试”）、易混元音、收音的发音方法、7 条音变规则（连音、鼻音化、紧音化等）、中国学习者常见误区；每个例子都可用 **女声 / 男声** 分别收听 |
| **拼读** | 选择初声 + 中声 + 终声，实时拼出音节并朗读；“拆字器”可把任意韩文拆成字母 |
| **词汇** | 9 个分类、100+ 高频词；翻卡记忆（键盘 ← → 空格）、列表浏览、标记掌握、只看未掌握、打乱顺序 |
| **短语** | 初次见面、购物点餐、出行问路、沟通求助、日常生活 5 个场景 |
| **语法** | 语序、은/는、이/가、을/를、이에요/예요、-아요/어요 |
| **日韩对照** | 为会日语的学习者准备：汉字词读音对应规律（收音 ㄱ↔く・き、ㄹ↔つ・ち…）、日韩同形汉字词、易混同形词（공부/工夫、애인/愛人…）、语体与敬语对照 |
| **测验** | 字母→罗马音、韩→中、中→韩、听音选词、日→韩五种题型，每轮 10 题，记录最佳成绩与正确率（键盘 1–4 作答） |

- **发音**：全站使用预先生成的神经语音音频（微软 SunHi 女声 / InJoon 男声，首尔标准音），共 649 条 × 2，所有设备效果一致。右上角可切换默认男声 / 女声，发音页、字母、短语、翻卡等处可直接对比。拼读器里带收音的任意音节等少数内容没有预生成音频，会用浏览器自带语音朗读。
  - 修改 `js/data.js` / `js/ja.js` 后重新生成音频（增量，只生成新增文本）：
    ```bash
    pip install edge-tts
    python3 scripts/gen_audio.py
    ```
  - 音频通过开源工具 [edge-tts](https://github.com/rany2/edge-tts) 生成，调用的是 Edge 浏览器“大声朗读”的在线服务（非官方接口，免费、无需账号）。
- **日语辅助**（默认开启，右上角「あ」按钮开关）：字母的假名近似读音与发音提示、会日语的发音捷径（ㄹ=ら行、紧音≈促音后的音、「ん」分三种…）、词汇的日语对应和汉字词标注、短语的日语说法及逐词对照、语法与助词的日语对照表。
- 学习进度（已掌握词汇、答题统计、连续学习天数）保存在浏览器 `localStorage` 中。
- 支持手机端与深色模式。

## 本地运行

直接双击打开 `index.html` 即可；或启动一个本地服务器：

```bash
python3 -m http.server 8000
```

然后访问 <http://localhost:8000>。

## 部署（GitHub Actions → GitHub Pages）

仓库自带工作流 `.github/workflows/pages.yml`，推送后会自动检查 JS 语法并发布到 GitHub Pages。

首次使用只需设置一次：

1. 打开仓库 **Settings → Pages**
2. **Build and deployment → Source** 选择 **GitHub Actions**
3. 到 **Actions** 页面重新运行 “Deploy to GitHub Pages”（或再推送一次）

发布成功后网址为：<https://cxelegy.github.io/KoreanLearning/>

也可以在 Actions 页面手动点击 **Run workflow** 随时重新发布。

## 目录结构

```
.github/workflows/pages.yml  自动发布到 GitHub Pages
index.html      页面骨架与导航
css/style.css   样式（含响应式与深色模式）
js/data.js      学习内容：字母、词汇、短语、语法、发音讲解
audio/          预生成的发音音频（f 女声 / m 男声）与 manifest.js
scripts/        collect-texts.js 收集朗读文本，gen_audio.py 生成音频
js/ja.js        日语辅助内容：假名近似、日韩对照、助词表、敬语
js/app.js       路由、朗读、拼读、翻卡、测验、进度存储
```

想添加词汇或短语，只需编辑 `js/data.js` 中对应的数组。
